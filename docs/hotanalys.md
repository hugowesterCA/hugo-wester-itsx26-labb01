# Hot analys

## Hot 1- Phishing via e-post

**Hot:** Angripare lurar anställda att klicka på skadliga länkar eller lämna ut inloggningsuppgifter.

**Sårbarhet:** Avsaknad av spamfilter och outbildad personal som inte förväntar sig eller känner igen detta.

**Skyddsåtgärd:** Skaffa spamfilter och utbilda personal inom phishing.

## Hot 2- Obehörig åtkomst till HR-systemet

**Hot:** känsliga uppgifter om anställda läcks till obehöriga.

**Sårbarhet:** Opatchade systemsårbarheter, svaga lösenord, för många som har tillgång till systemet som egentligen inte hade behövts.

**Åtgärd:** Regelbunden uppdatering/patchning. Starka lösenord, tillämpa zero-trust principen alltså endast dem som behöver ska ha tillgång till systemet.

## Hot 3- Insiderhot via mobiltelefoner

**Hot:** Anställda fotar känslig information eller delar av processen och sprider den.

**Sårbarhet:** Avsaknad av riktlinjer för mobilanvänding på företaget.

**Skyddsåtgärd:** Skaffa skriftliga riktlinjer för mobiler, informera personal om konsekvernser vid överträdelser. Begränsa mobilanvänding i kännsliga utrymmen/platser.
